TLH Ledger Backups

Privacy Policy

Effective October 1, 2026. This policy covers the personal TLH Ledger Backups tool maintained by cfirimar.

Data and purpose

The tool backs up the owner's local ledger database, which may contain imported transactions, positions, lot-selection records, recommendations, and bookkeeping events. Backup folders may also contain an uploaded CSV, recovery settings, sector-weight CSVs, and a verification manifest. This data is used solely for backup verification and recovery.

Google account permissions

The owner explicitly authorizes a Google account through OAuth. The tool requests https://www.googleapis.com/auth/drive.file to create, read, verify, and manage backup files created by the application. It does not request general access to unrelated Google Drive files. OAuth credentials and refresh tokens are stored locally on the owner's machines so scheduled uploads can run unattended.

Storage and sharing

Backup files are stored locally and uploaded to the authorized account's private Google Drive using rclone. They are not application-encrypted; access depends on the owner's machine security and Google account permissions. The tool does not make backups public, sell data, use it for advertising, or share it with other users. Google processes uploaded files as the chosen storage provider. API keys, notification tokens, and OAuth credentials are excluded from backup folders and the public website.

Retention and deletion

By default, the tool retains the latest 30 successfully uploaded backup folders locally and in Drive. Pending local backups are kept for retry. The owner can change retention or delete backups manually. Revoking authorization does not automatically delete existing backups.

Control and revocation

The owner can disable the backup service, remove its local OAuth configuration, and revoke Google access through Google Account connections. Future uploads stop once authorization is revoked. Existing files can be deleted through Google Drive, including its Trash if permanent deletion is desired.

This public website

These informational pages contain no portfolio records, login form, analytics code, or application cookies. GitHub Pages hosts the site and may process ordinary request information under GitHub's privacy statement.

Questions and changes

Contact the maintainer through the public website repository. Do not post financial records or credentials there. This policy will be updated if the tool's data practices change.
