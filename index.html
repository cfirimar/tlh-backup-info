TLH Ledger Backups

A personal backup tool that saves consistent copies of a locally hosted tax-loss-harvesting ledger to the owner's private Google Drive.

What it does

The tool runs on the owner's Raspberry Pi. It creates local SQLite snapshots after transaction or position imports and on a daily schedule, then uploads and verifies them using rclone. Failed uploads remain queued for retry.

Google Drive access

The tool requests the drive.file permission to create and manage its own backup files. It does not request general access to unrelated Drive files. The owner authorizes the destination Google account; backups are not publicly shared by the tool.

Personal use only

This website describes the tool. It does not provide access to the dashboard, accept portfolio uploads, or offer a public investment service. The actual ledger and dashboard remain on the owner's machine.
